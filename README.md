# 📊 Vrinda Store Annual Report 2022

An interactive Excel dashboard built to analyze sales and order performance for Vrinda Store in 2022.

---

## 🎯 Project Objective

The objective of this project is to analyze Vrinda Store's sales and order data and identify meaningful patterns in:

- Monthly sales and order trends
- Customer demographics
- Gender-wise sales performance
- Order status
- Top-performing states
- Sales channels
- Age-group and gender distribution

The dashboard is designed to present these insights in an interactive and easy-to-understand format.

## 📊 Dashboard

The dashboard provides an interactive view of sales and order performance using charts, Pivot Tables, and slicers.

### Dashboard Components

- 📈 Order vs Sales trend
- 👥 Sales distribution by gender
- 📦 Order status analysis
- 🗺️ Top 5 states by sales
- 👨‍👩‍👧 Age group vs gender analysis
- 🛒 Orders by sales channel
- 🔎 Interactive filters for Month, Channel, and Category

---

## 🔍 Key Insights

Based on the dashboard:

- Women accounted for **64%** of sales, while men accounted for **36%**.
- **Amazon** represented the largest share of orders among the displayed sales channels.
- **Maharashtra** recorded the highest sales among the top 5 states shown.
- **Delivered orders** represented the majority of orders.
- The dashboard allows sales performance to be explored across different months, channels, and product categories.

---

## 💡 Business Questions Answered

This dashboard helps answer questions such as:

1. How do sales and orders change throughout the year?
2. Which gender contributes more to sales?
3. Which states generate the highest sales?
4. Which sales channels generate the most orders?
5. How do different age groups contribute to orders?
6. What proportion of orders are delivered, returned, cancelled, or refunded?
7. How does performance change across different product categories?
